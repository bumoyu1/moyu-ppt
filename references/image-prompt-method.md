# 可见文案与参考角色

## 文案隔离

每页空间定位图末尾列出全部可见字符串，格式为：
```
可见文字=把问题说清楚；位置=标题带；角色=title
可见文字=2026 年第三季度；位置=右下来源；角色=label
```
“位置”“角色”等是指令，不能画进图片。允许真实内容本身含“标题”“步骤”等词，不用词语黑名单误杀正文。括号、引号、简繁按原文需要处理，不一律去除。样张内容、参考示例文字和角色 ID 都不得混入最终页面。

相同字符串若有多个位置，应在空间说明中明确出现次数。数据单位、标点、负号、比例及引用限定词与来源对齐。脚本只能检查清单与格式，不能自动证明语义忠实。

## 参考类型

| role | 稳定 ID | 传递内容 | 不传递内容 |
|---|---|---|---|
| family/style | S1 / family-P1 / S-board | 画风、处理方式、系统氛围 | 参考页文案、布局 |
| layout | L-content | 边距、标题带、栅格、层级骨架 | 内容、图片、颜色、字形 |
| typography | T-title 等 | 指定文字角色的字形、笔画、结构 | 示例文字、页面布局、背景、其他字体角色 |
| brand | C1 等 | 指定资产的身份及需保留的真实内容 | 整套风格默认值 |
| target | target | 需要编辑的当前页面 | 参考页代替目标页 |

manifest 中用结构化对象，最终顺序由生成器统一构建：target → family/style → layout → typography → brand。prompt/brief 使用稳定 ID，不手写参考图位置数字。只写路径的字符串按 generic reference 处理，不推断角色；新任务必须写角色。

## 字形参考

SZ 是独立的字号几何参考。存在 SZ 时，L 不再提供带锁标题的位置或大小；T 不提供大小，SZ 不提供字体。逐页可选 `[编辑底图]：[target] 路径`，必须以 `target_image` 导出，不能仅列作普通参考；准确编辑范围写在本页方案，输出另存。参见 [字号控制](title-size-control.md)。

具体制作与筛选见 typography-method.md。常见应用：
- 封面用 [T-display]，普通内容页用 [T-title]。
- 同一 [T-title] 可跨页复用，页内正文继续用 body 规范。
- body/data 只有确有必要时加样张，不用装饰标题样张支配所有字。
- 字形参考只约束结构；页面字号、位置和颜色取页面方案。
- 字体样张内出现的词不自动加入最终文案清单。

## 权重与冲突

S/L 是否附图由 styleWeight/layoutWeight 决定，规则见 [style-config-schema.md](style-config-schema.md)；T 由 typography.references 与页面声明决定，品牌资产 C 始终保留。

优先级：用户指定事实/资产身份 → 字形正确与可读 → 页面信息层级 → 版式/字形/风格各自的约束 → 材质与装饰。冲突时减少不相关参考，不能靠塞入更多图解决一切。图片数量超过能力上限时先缩减重复 S，再按页需要挑选，不静默删除必要 C/target。

## 模板与资产

多页拼贴先作整体分析；选定后取 originals 或用户原文件，裁出完整单页 L，保留边距，逐张看图确认。判断标准是版式骨架可辨，不以单页像素数代替判断，也不声称高分辨率生图可恢复不可辨信息。低清但骨架清晰的保留；不可辨时标记不足，优先找同模板来源补充。

风格来源不是模板时，可独立选择适合的版式参考；不要强制让同一张图片同时担任所有角色。组合参考逐项说明来源与作用。

C 按资产类型处理：LOGO/二维码保留结构与比例，人物/产品保留身份细节，IP 可进入新姿态场景。提示词不能保证像素精确；二维码必须实测可扫描，LOGO 必须与源图对照。当前图像版流程中无法达到要求时如实说明并请求用户决定交付方式，不把生成的近似图当精确资产。

## 编辑

改色/改字号：待修页作为 target_image，合格页或字体样张作为各自角色参考，明确只改哪些部分。没有待修页的“参考好页，其他不变”不可执行。生成器自动编号，去掉某张参考后不用手工改号码。修复后的图片重新做结构与文字检查。
