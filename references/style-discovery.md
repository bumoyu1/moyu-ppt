# 搜索前的风格沟通

先了解用户对整套PPT的想法，再去搜。目标是划定搜索范围，不是让用户代替设计师完成方案；用户不需要懂字体名、栅格或设计流派。本文件是搜索前风格沟通的唯一定义处，检索执行见[检索方法](inspiration-search-method.md)。

## 一次问清方向，不增加一轮审批

把下面这句并入首次需求沟通，已知项省略：

> 这份PPT，你希望观众第一眼感到什么？有没有喜欢或明确不喜欢的样子？用自己的话描述即可；还没想法也可以，我先找几个不同方向给你比较。

如果平台支持选项，可按这次用途给少量**不同表达目标**及“还没想法，先比较”。例如用于行业分享，可以比较“清楚可信，信息一眼能读懂”“有现场感，像在讲一个故事”“鲜明有个性，让人记住观点”。这些是示例，不是所有任务的固定菜单，也不要把第一项包装成默认正确答案。用户可以同时需要可信和鲜明。

喜欢的参考、品牌要求、讨厌的效果有就沿用；没有不追问。若用户只是说“高级”，且场合仍不能区分方向，用一句具体追问辨别“更在意简洁易读，还是更有视觉张力”等与当前内容相关的差异。不要用“极简高级／电影高级／奢华高级”互相解释。用户明确让你决定或先探索，直接按授权推进。

- **有具体想法**：记录用户原话及不希望出现的特征，围绕它找不同实现方式，不额外批准搜索词。
- **明确没想法**：记录开放探索；提出不同的设计假设。假设标为待比较，不把任意一种说成用户偏好。
- **有完整模板**：直接复用，停止风格问卷与泛搜。只缺字形或图像时，在已有系统中补对应角色。
- **只给主题并要求自主设计**：可以按授权找设计参考，但缺失的事实素材仍标缺口，不凭主题编造人物、数据或经历。
- **还没回复**：读文章、识别需要的页型、检查已有资产；不先按猜测颜色/材质检索，再把结果当用户的选择范围。等待不等于开放探索授权。
- **已经选过方向**：不重复询问。若用户否定结果，沿其反馈重写范围；问清被否定的是图像、字体还是整个表达方式，不把同样素材换几个词重新推荐。

## 把人话转成可以检索的设计问题

在 `inspiration-plan.json` 中保存简报和查询，字段见[检索方法](inspiration-search-method.md)。用户原话、设计师推断、内容需要分开写。每条查询要能回答：**为什么搜它，希望看见什么，找到以后用于哪个角色？**

| 用户表达或材料条件 | 设计师需要解决的问题 | 查询思路与限制 |
|---|---|---|
| “可信，但别像工作汇报” | 让人名、论点、证据层级清楚，同时有故事节奏 | 找叙事型presentation case study、人物/引语/时间线；不自动限定黑白或瑞士风 |
| “有游戏感，别廉价炫酷” | 游戏感来自世界、机制、像素还是叙事？正文如何保持可读 | 在已确认的表达范围内找完整游戏工作室/品牌演示案例；原画另列image-language，不在系统查询里先塞金色/霓虹 |
| “热烈、节庆、有感染力” | 色彩和标题怎样承载情绪，普通内容页怎样延续 | 找活动视觉系统与内容页，再补标题处理；不能强行矫正为冷淡极简 |
| “正式，很多数据” | 同口径比较、图表标注、数字层级与投影阅读 | 找报告/数据presentation及具体图表页型；不要用宏大建筑代替数据设计 |
| “还没想法，你先找” | 找出少量能让用户做判断的不同方案 | 可提出编辑叙事、摄影故事、图解系统等适合本次内容的假设；每个都有版式依据，不固定同一组方向 |

避免一条查询混入行业、情绪、配色、材质、字体和图表要求。分两条线：

1. **版式依据**：完整案例、内容页结构与信息层级，先回答内容怎样排。英语案例可借结构；中文字体按[字体方法](typography-method.md)直接设计，用实际文字验证字密度、断行与标题正文对比。
2. **图像补充**：与版式或文章内容相关的静态图像（插画、摄影、图形、材质），只回答画面怎样表现，选定后作为部件融合进版式。可以共享同一方向，但不能代替第一条线。用户只要图像补充时无需重搜整套设计。

“高级”“有品味”“电影感”不能单独当搜索简报或入围理由。诸如“标题最多两行、正文左对齐、人物图与证据分区”才是可以比较、验证和迁移的处理；这些是设计假设，要经图片和样页检验。

## 把结果变成可选方案

搜回来的图做成编号图库，由用户自己挑（见[检索方法](inspiration-search-method.md)）：agent 不替用户按风格或质量删图，也不先定方向再找配图。用户挑完，agent 再把挑中的图归纳成方向：每张提供什么（版式、内容页、画法、配色、图像部件）、整体感觉、内容页怎么排、中文标题/正文/数字的处理，以及看得到的限制（如只有封面）。限制如实告诉用户，换不换由用户决定。

每个方向的字体搭配按[字体方法](typography-method.md)从内容和风格推导，写成用户看得懂的建议；不必先为每个方向配齐外部字体图片。

用户选方向后，再用本次材料的标题与正文做代表样页验证；只为选定方向生图，未选方向停留在检索图与字体建议。
