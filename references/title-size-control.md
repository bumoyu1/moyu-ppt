# 同画幅字号样板与模板编辑

本文只用于用户选了统一版式的作品；自由构图不锁标题，不做字号样板，也不测字号（见[标题排版](visual-director-method.md#标题排版统一版式或自由构图)）。

目标是提高同一套幻灯片标题大小和位置的重复性。当前字号锁是提示词几何约束与生成后测量，不是排版引擎的硬锁；同画幅参考也不能保证像素完全一致。

## 三类参考各自负责什么

- **T 字形样张**：笔画、部首、字面重心与字距。不提供字号或页面坐标；紧裁大字图不充当字号样板。
- **SZ 字号样板**：与目标幻灯片同一画幅、最好同一像素尺寸；把一组文字放在实际位置，展示真实墨迹高度。它只传几何，未指定为字形参考时不迁移其字体、文字、颜色、背景或留白布局。
- **L 版式参考**：SZ 存在时只借正文区结构、栅格与留白，不从 L 继承带锁标题的位置和大小。S、L 尽量避开残留标题、标志和其他尺度线索。

标题高度和定位只有一处权威几何说明。按字数估算的行宽用于布局预算，不要求同时顶满四边；保持字形比例，行宽自然形成，不拉宽、不压扁、不放大填满空白。

## 首张样页前：准备几何样板

还没有经用户认可的内容页时，可用本机原生字体制作精确的几何参考。这是代码原生的辅助图，不是幻灯片文字成品，不调用生图，也不改已有页面。

```bash
python3 "{SKILL_DIR}/scripts/text_lock.py" guide \
  --canvas 1672x941 --text '八字内容标题示例' \
  --font '/本机真实字体路径/中文字体.ttf' \
  --ink-height 6.2 --left 5.5 --top 5.5 \
  --background '#8FE1FC' --color '#000000' \
  --out assets/typography/size-title.png
```

`--ink-height`、`--left`、`--top` 为画布百分比，按文字真实墨迹计算，不把字体 point size 当作墨迹高度。输出 PNG 和 JSON，记录字体、画幅、实际墨迹框、误差与 geometry-only 用途。先看图确认无缺字、无裁切，核对报告后再引用。没有支持实际汉字的字体时如实说明，不用方框字当合格样板。

在全篇常量块写入现有字号锁声明：

```text
- 字号锁 标题：字高 6.2%，顶 5.5%，左 5.5%，最宽 70%，字数 7–9，样板 assets/typography/size-title.png
```

可见文字清单继续使用 `锁=标题`。拆分脚本为这组的每页自动附同一张 `[SZn]`，包括稳定、变奏、亮点页；无需每页再生样板。

几何样板通过只代表参考本身正确，不代表生图输出合格；样页检查点照常进行。

## 样页确认后：使用实际认可的字号

请用户指定字号合适的内容页，再用已有 `text_lock.py template` 从该页提取同尺寸、仅含锁定行的样板。以用户认可页的实测高度和定位更新锁声明，重新拆分余页。不要为了让测量通过，擅自把目标改成某张超差图的实测值。

标题有几个位置不同的组（如左上、右上、居中）时，每个组都用这一页的字做样板：`template --page N --group 标题 --as-group 标题右 --out assets/typography/size-title-right.png` 把认可的那一行字按新组的字高放到新组的位置。真实字形的样板比几何样板更能定住字号，样页确认后就把几何样板换掉。

T 已由清楚的编辑底图传递时，可不再附紧裁的同角色 T，减少尺度竞争；仍保留该角色的文字规范和字形检查。原生几何字体与目标像素/书法字不同，是需要检查的残余干扰。

## 明确使用模板编辑

只在正文骨架可复用，或本页方案明确允许正文重排时使用，不把全套内容强行做成一种布局。在该页空间定位图之前声明：

```markdown
**[编辑底图]**：[target] assets/templates/content.png
```

路径含空格时给完整路径加引号。目标图必须真实存在且可解码，输出必须另存，不能与目标相同。该字段机械生成 `edit: true` 与 `target_image`，普通和 `--single-phase` 清单都保留；不会把编辑底图伪装成普通 family 参考，也不自动叠加另一张族锚。

本页方案写清编辑范围，例如：

> 以底图保留画风、标题字形和字号结构，主标题换为本页清单文字并服从 SZ；允许重排标题下的正文区，按本页流程/矩阵重新绘制。旧标题、旧正文和旧数据不进入本页，其他元素按本页方案决定。

单点修标题时则明确只改标题及旧字痕背景，正文、金额、周期与布局保持。局部编辑和新页面迁移是两种验证任务，分别报告，不能把一次修正当作跨页一致性证明。

## 每批只测量，不自动重画

```bash
python3 "{SKILL_DIR}/scripts/text_lock.py" check \
  --manifest manifest-pilot.json --report text-lock-report.json
```

同时核对字符、单位、正文保真、字形比例和字高/位置。报告测的是墨迹框，不是字体文件字号；看图确认定位到的确是该标题。保持既定容差，不为通过而放宽。

首批代表页检查后再扩至全篇。正常生产不逐页做多组 A/B；仅在控制方式不确定时做有限对照，同页重复与新标题/新布局迁移分开统计。模型身份不公开时记 platform-managed，不能宣称固定模型或种子。

## 边界

同画幅样板在小规模对照里减小了字高误差，但输出仍可能偏小，字宽也会变化。它只是辅助，不保证全篇可靠，也不保证像素一致；出图对照属于 platform_image_smoke，与离线脚本回归分开记录。
